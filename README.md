# 高企查询 — 高企认定 知识产权「是否被报过」批量查重

给一串 13 位专利申请号，自动在高企认定系统里逐条判定：**这条知识产权往年有没有被别的公司拿去报过高企**，最后输出一张 CSV。

---

## 怎么装

这个包既可以当 WorkBuddy 技能装，也可以纯命令行用。

**A. 装成 WorkBuddy 技能（推荐）**

把整个 `高企查询/` 目录放到技能目录下，然后重启 WorkBuddy：

```
Windows : %USERPROFILE%\.workbuddy\skills\高企查询\
macOS   : ~/.workbuddy/skills/高企查询/
```

重启后直接对 WorkBuddy 说「高企查询：<专利号…>」或「查这些专利有没有被别的公司报过高企」就会自动触发。

**B. 纯命令行用**

不用装，解压后直接 `python scripts/gqqy_check.py` 跑就行，见下面「快速开始」。

---

## 它是怎么判的（先看懂这个再用）

高企系统**没有只读查重入口**——右上角那个「查找」按钮只是刷新当前列表，
内部的 `findIpBySqh.do` 也只查佰腾专利库（有没有这个专利、权利人是谁），**不带高企查重信息**。

唯一能拿到「是否被别的公司用过」的地方，是**「添加知识产权」保存时服务端返回的页面**：

| 保存响应 | 结论 | 是否入库 |
|---|---|---|
| 红字横幅「XX公司于YYYY年，使用该知识产权（ZL...）如有问题请进行【知识产权申诉】！」 | **报过** | **否**，服务端直接拒绝 |
| 正常渲染列表，出现该专利号 | **未报过** | 是 → 脚本**随即勾选删除**，不留痕 |

> ⚠️ 所以这个工具**会往真实的申报记录里临时写一条再删掉**。
> 它选的是「申报材料填写中」的记录（默认列表最上面那条），并且每条查完立即清理。
> 跑完可以自己看一眼「知识产权列表」和「已用II类知识产权」两张表，都应该是 `共0条`。

## 前置条件

| 项 | 要求 |
|---|---|
| Python | 3.8 以上（无第三方依赖，标准库就够） |
| browser-skill | 提供 `bsk` 命令行 + 浏览器扩展，且扩展已启用。`bsk status` 能看到 `browsers connected 1` |
| 登录态 | 浏览器里已登录高企认定系统（脚本**不碰登录框**，只复用你现有的登录态） |
| 载体记录 | 至少有一条状态为「申报材料填写中」的申报材料（已提交的没有「修改」入口，不能用） |
| 开放时间 | 系统维护期业务系统**只在工作日 8:30–17:30 开放**。非开放时段站点直接连不上，**那不是网络问题，别去改代理** |

## 快速开始

```bash
# 1) 环境 + 登录 + 导航自检
python scripts/gqqy_check.py setup

# 2) 批量查重（专利号直接跟在后面，空格分隔）
python scripts/gqqy_check.py check 2024229404464 2019100219685 2023205992898

# 或者从文件读（一行一个 / 空格 / 逗号都行）
python scripts/gqqy_check.py check --file nums.txt --out 结果.csv
```

### 常用参数

| 参数 | 说明 |
|---|---|
| `--out 结果.csv` | 指定输出路径；不写则生成 `高企知识产权查重结果_YYYYMMDD_HHMM.csv` |
| `--record N` | 用第 N 条申报材料当探测载体（默认 1 = 最上面那条，通常是最新年度） |
| `--session <id>` | 指定 bsk 会话；**一般不用管**，脚本会自动复用现有会话 |
| `--json` | 额外打印完整 JSON，便于二次处理 |
| `--no-clean` | 未报过的记录**不删除**。⚠️ 会把脏数据留在真实申报里，除非你明确知道自己在干嘛，否则别用 |

环境变量 `BSK_BIN` 可指定 bsk 路径（脚本会自动探测，装得偏才需要）。

CSV，UTF-8-BOM，Excel 直接双击就能开：

| 序号 | 专利号 | 是否报过 | 使用公司 | 使用年份 | 类别 | 处理状态 | 备注 |
|---|---|---|---|---|---|---|---|
| 1 | ZL202422940446.4 | 是 | 湖北同邦达科技有限公司 | 2025 | 实用新型专利 | 报过 | |
| 2 | ZL201910021968.5 | 否 | | | 发明专利（非国防专利） | 未报过 | |

- **类别自动推导**，不用你指定：申请号**第 5 位** `1`=发明、`2`=实用新型、`3`=外观设计、`4`=软件著作权。
- **专利号写法随便**：`2024229404464` 和 `ZL202422940446.4` 都认，脚本会统一成系统要求的格式。
- `处理状态` 可能出现 `未知` / `需人工介入` / `格式错误`，对应 `备注` 里有原因。

## ★ 一次跑批全是「否」时，务必做对照

如果整批结果都是「未报过」，**先别急着交付**——万一脚本检出能力失效了（页面改版、弹窗没开出来），
表现就是"一片全否"，这比漏检更危险。

拿一条**已知报过**的号单独再跑一次做对照：

```bash
python scripts/gqqy_check.py check 2024229404464 --out _对照.csv
```

- 对照回「报过」→ 检出正常，全否是真实结论，可以交付。
- 对照也回「未报过」→ **检出已失效**，结果不可信，先跑 `setup` 重跑再说。

## 排错

| 现象 | 处理 |
|---|---|
| `[环境检查未通过] 未找到 bsk 可执行文件` | 先装 browser-skill，或设 `BSK_BIN` |
| **脚本跑了几分钟完全没有输出（像卡死）** | bsk daemon 已经死了。见下面「daemon 会被回收」 |
| `[环境检查未通过] bsk daemon 探活超时 / 没有在运行` | 同上，按提示重启 daemon |
| `[环境检查未通过] 没有连上浏览器` | 浏览器扩展没启用，`bsk browsers` 检查 |
| `需人工介入: 不在知识产权汇总表页` | 先跑 `setup` |
| `需人工介入: 找不到「高企认定申报」入口` | 页面没加载完或结构变了，重试一次；仍失败人工开首页看看 |
| `需人工介入: 已登录、但停在统一身份认证门户` | 门户 iframe 没渲染完（入口那一列还没出来）。再跑一次即可；持续失败则人工点一下 |
| 报 `未检测到登录态`，但浏览器明明已登录 | 看当前页是不是「统一身份认证与单点登录平台」门户页——旧版脚本会把门户页误判成未登录，升级脚本即可 |
| `navigate` 报 `operation timed out ... 30s` | bsk 内部 RPC 上限，页面多半已跳成功，脚本会自动重判，可忽略 |
| `需人工介入: 添加弹窗未就绪` | 弹窗没弹出来，重试 |
| 站点连接被拒 / `ERR_CONNECTION_CLOSED` | 不在开放时段（工作日 8:30–17:30） |
| 跑完发现列表里多了记录 | 用 `--no-clean` 跑过？手动勾选那条点「删除」即可 |

### daemon 会被回收 —— 最常见的「卡死」原因

`bsk` 的 daemon 是常驻进程。如果它是在**一次性的命令行环境**里被拉起来的，
那条命令一结束，daemon 可能被跟着回收；此后所有 `bsk` 命令都会**一直挂着不返回**
（`bsk status` 实测 >90s 也没有任何输出），脚本看起来就是「卡住、没有任何输出」。

处理：

```bash
# 1) 在一个「能常驻」的后台任务里把 daemon 起起来（别用一次性命令）
bsk daemon start --foreground

# 2) 之后每条命令都带 BSK_AUTO_START=0：
#    既不让它反复尝试拉起，也让「起不来」立刻报错而不是干等
BSK_AUTO_START=0 python scripts/gqqy_check.py check --file nums.txt
```

自检已内置 25s 快速探活，daemon 没起来会直接把上面这条恢复指令打出来。

### 两个环境特性（不是 bug）

- **新建会话的窗口先落在「统一身份认证门户」**，要经「我要办理」进高企系统。
  脚本已自动处理；若你的机器上跳转失败，会明确提示而不是判成「未登录」。
- **号码必须 13 位**（12 位 + 1 位校验位）。少一位会标 `格式错误` 而**不会**被误判成「未报过」，
  放心。

## ⚠️ 安全与合规须知

**这个技能会向外部系统写入数据，请务必读完再运行。**

- **会写入高企认定系统**：判「未报过」的依据是「添加知识产权」的保存响应，
  因此脚本会**真实地向系统插入一条记录**，再自动勾选删除。系统本身没有只读查重入口，这是唯一可行的判定路径。
- **默认行为是「用完即删」**：每次探测只留 1 条记录，随即删除，列表回落`共0条`。
  想保留现场排查，加 `--no-clean`（**危险**：会在你的申报材料里留下真实记录）。
- **只删自己刚插入的那一条**：清理逻辑先确认列表里有勾选行，再点删除，并校验删除后的剩余条数。
  清理未确认时会写进 CSV 的「备注」列，不会假装成功。
- **不碰账号密码**：脚本靠共享你本机浏览器已登录的会话工作，不读取、不存储任何凭据。
- **只访问官方站点**：`gqqy.chinatorch.org.cn` 与 `hjrz.chinatorch.org.cn`，无第三方外网请求。
- **命令执行不经 shell**（`subprocess.run([BSK] + args)`），无命令注入面。
- **有逃生开关**：任何异常情况都可用 `--no-clean` 立即停止写入行为。

**请仅在你有合法权限的申报账号上使用，并遵守高企认定平台的使用条款。**
批量跑之前，建议先用 1~2 个已知结果的专利号做正样本对照，确认判定方向正确（见上文「对照」章节）。
